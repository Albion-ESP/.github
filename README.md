### Do I need to run it as Administrator?

No. This repository contains informational reference material and does not interact with the Albion Online game process.

### Will antivirus software flag it?

The reference does not include a functional ESP executable, radar overlay, or game modification loader. Review downloaded files with your security software before opening them.

### Is it compatible with Windows 11?

The reference is organized for Windows desktop use and does not modify game files or interact with the game client.

### Does it reveal hidden players or resources?

No. It explains standard visibility and map systems but does not reveal hidden entities, player positions, or information unavailable through normal gameplay.

### Does it include a radar or wallhack?

No. It covers radar and wallhack terminology for informational purposes without providing a functional overlay or wallhack.
